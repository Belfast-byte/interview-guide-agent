## 已观察到的 Judge 局限

以下为子 Agent 复核观察，不是人工真值标注：

- 正常开放题未被当成“没有唯一答案”的缺陷；错误前提、缺少实验参数、不聚焦、直接代答及重复的主要问题能够被识别，正常故障追问也能与重复区分。
- 早期提示下，首题的 REPETITION 理由错误地检查题内重复词句。已明确改为与历史题目/已验证内容的重复，完整空历史应说明没有历史可重复。
- 代答样例被额外标为不可回答，重复样例被额外标为不聚焦；还有引用未提供的历史 target、假定有限作答时间等过度推断。已补充六维独立判断及来源边界，并单独复验典型样例。
- 最后一次三例复验中，合理追问六维均未报问题；代答的 ANSWERABILITY、重复题的 FOCUS 附加告警仍然复现。它们是需要人工复核的过度归因，未被后处理抹掉，也不能宣称提示修订已经消除了误报。
- 实际调用可能耗时数十秒乃至超时。超时保留为 FAILED，后续样例记 PREVIOUS_CALL_TIMEOUT；unknown usage 不记作零费用。

人工标注、误报/漏报统计及跨运行一致性校准尚未完成，报告保持 `humanReview=PENDING`。当前交付是可运行的观测与测评能力，不代表六维 Judge 准确率已被证明，不能据此启用自动发布门禁或候选人评分。
