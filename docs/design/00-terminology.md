# AI Interview Platform

该上下文描述平台如何通过动态面试收集候选人的能力证据，并生成可追溯的面试报告。

## Language

**Agent 面试（Agent Interview）**:
一种围绕考察目标运行的动态面试；系统在每轮回答后选择追问、切换目标或结束，而不是预先播放完整题单。
_Avoid_: 智能题单、自适应题库

**考察目标（Assessment Target）**:
一场 Agent 面试需要验证的具体能力方向。MVP 固定包含技术理解、项目实践和问题解决三个目标。
_Avoid_: 题目分类、知识点标签

**面试轮次（Interview Turn）**:
一个面试问题、候选人回答以及由该回答产生的 Agent 决策所组成的完整交互单元。
_Avoid_: 题目、消息

**能力证据（Evidence）**:
从候选人回答中提取、能够支持能力判断且可定位到原始回答片段的信息。
_Avoid_: 简历信息、模型推测

**决策动作（Decision Action）**:
Agent 在处理一轮回答后选择的下一步行为。MVP 只允许继续追问、切换目标和结束面试。
_Avoid_: 工具调用、工作流节点

**证据报告（Evidence Report）**:
按考察目标组织的面试结果，每项结论均引用产生该结论的原始面试轮次和回答片段。
_Avoid_: 百分制成绩单、录用结论
