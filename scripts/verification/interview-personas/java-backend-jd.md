# Java 后端开发工程师（虚构测试岗位）

面向有 3 年左右经验的开发人员，负责商户订单、库存和报表系统的后端开发。

职责包括需求分析、接口开发、业务数据一致性维护、自动化测试和线上问题排查。

岗位要求：

- 能使用 Java、集合和线程池完成业务开发，解释线程安全与资源管理问题。
- 能使用 Spring Boot 和 MyBatis，理解事务的生效条件、回滚和外部调用边界。
- 掌握 MySQL 查询与索引，能够分析并发更新、锁等待和慢查询。
- 能合理使用 Redis，解释缓存一致性、请求去重和锁的适用边界。
- 能使用 RabbitMQ 处理异步业务，说明重复消费、重试和失败处理。
- 能结合订单、库存和导出任务说明自己的实现，分析异常路径及方案取舍。

考察重点是实际理解和可解释的工程判断，不以术语数量或回答篇幅衡量能力。
