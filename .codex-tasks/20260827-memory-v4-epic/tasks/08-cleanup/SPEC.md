# T07 删除旧路径与端到端验收

## Goal

代码库只保留三层记忆 v4 路径，并用 Redis persistence 场景证明正式评估、练习消费和 ActionIntent 恢复闭环。

## Scope

- 删除无消费者的旧 Topic/Claim 领域、仓储、表、迁移和测试。
- 删除失效 Prompt 字段、旧响应、兼容分支、backfill、双写和空包。
- 验证正式面试只做中性召回与独立评估。
- 验证练习模式按 scope 消费 Semantic 和完整 Episode 诊断。
- 验证 Intent 三个中断位置恢复无重复副作用。
- 在 60 秒硬超时内运行后端全量测试，并构建前端。

## Non-Goals

- 不迁移旧数据，不保留旧 API 或旧表兼容。
- 不新增通用安全层、配置开关或扩展框架。

## Done When

- 规格列出的目标表之外不存在旧记忆表和运行分支。
- 三个场景有直接自动化测试证据。
- 后端全量测试、前端构建、静态检索和 diff 检查通过。
- 本 Epic 改动全部提交，工作树只剩用户原有改动。
